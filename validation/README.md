# Validation

CytoWeave's analyses are reimplementations of published methods. The unit
tests (`web/lib/*.test.mjs`) check each function in isolation. This folder
checks the complete pipelines, the way they run in the app, against answers
that are known in advance:

- **Simulated experiments with ground truth.** The bundled examples are
  generated by `web/lib/simulate.js`. The simulator keeps the truth for every
  event: its cell type, its fluorochrome abundances, which events fall inside
  a clog or bubble, and the true spillover, phase fractions, precursor
  frequencies and batch effects. The checks compare CytoWeave's results with
  that truth.
- **Published reference values.**
  - Statistics from R 4.x on R's `sleep` data set.
  - BD's FlowJo transformation lookup tables, published under the MIT
    licence. A subset is in `data/`; the licence is in
    `data/LICENSE-BD-FlowJo-LUTs.txt`.
  - Identities from the literature, such as logicle with W = 0 being
    Gating-ML's fasinh.

## Running the checks

With Node.js 22 or later, from the repository root:

```bash
node validation/run.mjs
```

The run needs no network or downloads and takes about 15 seconds.

| Option | Effect |
| --- | --- |
| `fcs`, `compensation`, `gating`, `qc`, `spectral`, `cellcycle`, `proliferation`, `clustering`, `normalization`, `debarcode`, `transforms`, `reference` | Run only these suites |
| `--verbose` | Print every check, not only failures |

The command exits with status 1 when a check fails. Continuous integration runs
every suite on each pull request and each push to `main`
(`.github/workflows/ci.yml`).

## Notes

### FlowJo's biexponential is not a logicle

FlowJo's default fluorescence scale is its legacy "biex". It is often
described as a logicle with W = log10(|width basis|) / 2, but it is not one.
It is a 4097-point table built by TreeStar's own algorithm and read with
linear interpolation. CytoWeave ports that algorithm from FlowKit's
`generate_biex_lut` (BSD-3), keeping the legacy code's quirks.

Against BD's published tables, the earlier logicle approximation was off by up
to 20 of 4096 channels at width basis −1000, and about 4 channels at FlowJo's
default of −10. The port matches to the tables' printed precision.

BD's tables for width bases −1, −1.58 and −2.51 are identical to the table for
−3.16. FlowJo therefore clamps the width basis at −√10, and CytoWeave does the
same.

FlowJo's own *logicle* also departs from the Moore–Parks reference by up to
about 100 channels at W = 1 (see `cytoweave-spec/research.md`, §3A.2).
CytoWeave implements the reference logicle, as Gating-ML specifies.

### What a simulated truth can and cannot show

Simulated data test the software against answers that are known exactly,
which real data cannot provide. They do not test whether the simulator is
realistic. The simulator models the effects that make real analyses hard:
- spillover and spreading from photon statistics;
- lymphoid and myeloid autofluorescence;
- dead cells, debris and doublets;
- clogs, bubbles and drift;
- batch effects and bead-measured sensitivity loss.

Real data can still fail in ways it does not model. Comparisons with
FlowRepository datasets and with FlowKit, flowCore, PeacoQC and FlowSOM on the
same files are on the roadmap.
