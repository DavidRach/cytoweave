# Changelog

## 0.1.0 (2026-10-02)

First release.

### Program

- One program for macOS, Linux and Windows (x64 and ARM64), with installers
  that verify checksums. It opens as a desktop window, and a second launch
  hands its files to the open window.
- A workspace library that stores each FCS file once by SHA-256, so
  workspaces survive moved and renamed files.

### Data

- FCS 2.0–3.2 reading, with repairs of common vendor deviations, each listed
  in the sample's diagnostics. FCS 3.1 writing for exported populations.
- Sample annotations from file names or CSV tables.
- Nine example experiments generated by a physical simulator, with the
  ground truth of every event, including a FlowJo workspace to migrate and a
  pooled, palladium-barcoded mass cytometry plate. Event counts per
  population follow multinomial sampling, so replicate tubes differ as real
  ones do.

### Gating and statistics

- Rectangle, polygon, freehand, ellipse, quadrant, range and split gates, and
  a magic wand.
- Gates are shared across samples, with per-sample overrides and group
  scopes.
- Pseudocolor, dot, density, contour, zebra, histogram and cumulative plots,
  backgating and overlays.
- Scales: logicle (reference implementation), arcsinh, log, linear and
  FlowJo's biexponential. The biexponential is reproduced exactly, matching
  BD's published lookup tables, including FlowJo's clamping of the width
  basis at −√10.
- Review of a gate across samples, and boundary robustness.
- Batch statistics tables, and group comparisons with tests chosen from the
  design, effect sizes, confidence intervals and multiple-testing
  correction.

### Compensation and spectral

- Spillover from single-stain controls, by median difference or robust
  regression.
- A check of any matrix against its controls. It suggests corrections, which
  are applied in place or, for a file's matrix, in a corrected copy. It flags
  autofluorescent positives instead of "correcting" them.
- Spillover spreading matrix and N×N pair plots.
- Spectral unmixing:
  - reference spectra gated automatically from the controls;
  - one or several autofluorescence signatures, or per-event
    autofluorescence;
  - OLS, WLS and NNLS;
  - complexity index, similarity and spreading matrices;
  - residuals, and a comparison of unmixing models on the user's sample.

### Quality control and normalization

- PeacoQC (classic, and a refined default that leaves clean and drifting
  files alone), a flow-rate check, margin events and drift, with scores and a
  cohort overview.
- CytoNorm with a confounding check; bead normalization; debarcoding, with a
  key that names codes after their samples and a split of a pooled file into
  one sample per code.

### High-dimensional analysis

- FlowSOM and Leiden clustering; UMAP, t-SNE and PCA across samples.
- Cluster names from marker enrichment.
- Faithfulness of every map: trustworthiness, continuity, kNN preservation,
  sample mixing, seed stability and unreliable regions.
- Differential abundance of clusters.

### Specialized analyses

- Cell cycle (Dean–Jett–Fox, Watson) and proliferation (generation fitting
  and Roederer's indices).

### Output and provenance

- Publication figures that stay live until export as SVG, PNG or PDF.
- A methods paragraph with references, written from the workspace, and a
  MIFlowCyt checklist.
- Undo and redo, a change log, and checkpoints with a semantic diff and the
  effect of the changes on every frequency.

### Interchange

- FlowJo 10 workspace import with a per-population fidelity report and a
  count comparison.
- Gating-ML 2.0 import and export.
- CLR export; ACS containers.

### Automation

- `cytoweave mcp`, a Model Context Protocol server with 15 tools for AI
  agents, acting in the visible window.
- `--remote-control` for local scripts.

### Validation

- Unit tests for every analysis module.
- An end-to-end validation suite (66 checks) against simulated truth, BD's
  FlowJo lookup tables and R.
