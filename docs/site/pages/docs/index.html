Quick start

  1. Install CytoWeave with one command.
  2. Run cytoweave in a terminal. It opens its own window.
  3. Open an example experiment from the start page and click Add suggested gates, or drop your own FCS files or a folder on the window.
  4. Work through the views in the bar at the top: Gate, QC, Compensate, Spectral, Explore, Tables, Compare, Figures and Report.
  5. Press ⌘K (Ctrl+K) to find any sample, population, channel or command, and ? for every keyboard shortcut.
